Consensus extension module for BABE consensus. Collects on-chain randomness
from VRF outputs and manages epoch transitions.

License: Apache-2.0

## QUIP-31 audit remediation (F1)

Epoch rotation consumes every randomness segment, including the actively filling
tail. The segment index advances only on a deposit after the current segment is
full, so this also fixes the exactly-256-output boundary. Each segment is taken
from storage; partial outputs cannot carry over to another rotation. Storage
layout, clients and genesis are unchanged.

Five regressions deposit real hybrid VRF outputs and construct the expected hash
input independently of storage: one output, two outputs, 256 outputs, 257 outputs,
and consecutive epochs followed by an empty epoch. All five fail on the original
`d511a17` production implementation and pass with the inclusive segment range.

The test harness first needs the crypto dev-dependency, `HybridVrf` in scope and
an explicit `VrfSecret::vrf_sign` call. After that compile repair, the original
suite has six failures. All six are fixture defects: its two pre-seal headers
were identical, and deterministic hybrid signing produced identical sealed
headers. The equivocation checker correctly rejected them. Giving the second
header a distinct digest before signing, and checking the generated proof,
restores all 31 original tests without changing production equivocation logic:

| Test | Base after compile repair | Distinct-header fixture |
|---|---|---|
| `report_equivocation_after_skipped_epochs_works` | `InvalidEquivocationProof` | Pass |
| `report_equivocation_current_session_works` | `InvalidEquivocationProof` | Pass |
| `report_equivocation_invalid_key_owner_proof` | `InvalidEquivocationProof` masks the intended ownership check | Pass |
| `report_equivocation_old_session_works` | `InvalidEquivocationProof` | Pass |
| `report_equivocation_validate_unsigned_prevents_duplicates` | Invalid proof prevents duplicate checking | Pass |
| `valid_equivocation_reports_dont_pay_fees` | `InvalidEquivocationProof` | Pass |

The benchmark's old 416-byte proof also failed to decode as a hybrid proof. Its
replacement is generated by `generate_equivocation_report_blob`; that test checks
the stored bytes against the generated proof to keep the fixture reproducible.

The final-primary-author residual is **not closed** by F1. A further one-session
commitment delay requires a session-pallet change and 8–12 hours of key-rotation
latency. That is a separate ticket, deliberately outside runtime 120.
